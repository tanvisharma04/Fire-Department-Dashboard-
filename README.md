# Fire Department Emergency Response Performance Dashboard

## Project Overview

An interactive Power BI dashboard designed to monitor emergency response performance, evaluate response-time target compliance, and compare operational metrics across reporting periods and sites.

The dashboard consolidates key performance indicators, time-based comparisons, and automated performance commentary into a single reporting interface to support operational monitoring and data-driven decision-making.

> **Data Privacy Notice:** The underlying dataset is private and is not included in this repository. The dashboard screenshot is shared solely to demonstrate the report design, analytical approach, and Power BI capabilities.

## Business Objectives

- Monitor average emergency response time.
- Track the number of emergency responses meeting the target response time.
- Compare response-time performance across months and quarters.
- Evaluate performance across selected sites and years.
- Present summarized performance findings through KPI cards and dynamic commentary.

## Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard includes KPI cards displaying:

- Previous Quarter Average
- Slowest Response
- Percentage of Responses Within Target
- Responses Within Target
- Quarter Performance Status
- Average Response Time
- Total Emergency Responses
- Quarter-over-Quarter Difference

### 2. Interactive Filters

Users can filter the report by:

- Site
- Month
- Quarter
- Year

These filters support focused analysis of emergency response performance across different reporting periods and locations.

### 3. Response-Time Analysis

Visual comparisons show average response time against the target response time at monthly and quarterly levels.

A site-level visual provides an additional view of response-time performance for the selected location.

### 4. Performance Commentary

A dynamic commentary panel summarizes selected-period metrics, target compliance, and changes compared with the previous quarter.

This feature helps translate numerical results into a concise operational summary.

## Key Insights

The following observations are based on the dashboard's currently displayed filter selection:

- **Average response time:** 3.14 minutes.
- **Target compliance:** The dashboard reports five responses within the target, with 100% target compliance.
- **Response-time target:** The commentary identifies a seven-minute target.
- **Quarter-over-quarter change:** Average response time decreased by 0.53 minutes compared with the previous quarter.
- **Historical metrics:** The dashboard displays a previous-quarter average of 2.61 minutes and a slowest response of 4.47 minutes.

These figures represent the selected reporting period and should not be interpreted as department-wide results.
